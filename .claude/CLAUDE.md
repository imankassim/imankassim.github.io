# Commit and pull request rules

- Commit messages are a single short line of about five words, such as "Rename immy and tidy highlight".
- No commit message body, no Co-Authored-By lines, no session links and no other trailers.
- Pull request titles follow the same rule. Pull request descriptions are one or two plain sentences with no footer or links.
